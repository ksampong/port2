Embodied AI Robotic Lamp / Robotic Arm

Embodied AI + Robotics · 2026

Built an integrated embodied-AI prototype combining servo control, on-device perception, memory events, and conversational interaction.

  • [CONTROL] 6DOF MG996R arm + Raspberry Pi 4B + Waveshare PCA9685 + ServoKit; stable empirically selected poses, smoothed movement, and a camera-stable wrist strategy using primarily joints 0–3.
  • [PERCEPTION] Picamera2 stream (640×480 BGR888) served to independent clients; MediaPipe FaceMesh + YOLOv8n with attention states LOOKING / NOT_LOOKING / NO_FACE and distance-sensitive detection behavior in testing.
  • [MEMORY] Timestamped JSONL event streams for attention, scene/object events, and fused state used as lightweight IPC. Historical object-location recall is experimental/incomplete.
  • [BEHAVIOUR] IDLE → person detected → attention check; disengagement triggers a tuck-and-sweep sequence until threshold is met, then returns home.
  • [CONVERSATION] USB mic + Vosk ASR + laptop-hosted Ollama LLM + TTS; hard-coded timed responses also used during system tests due to latency/hallucination limits on small local models.
  • [EVALUATION] 8/8 engagement blocks reached required state; 7/8 with no incorrect transitions (2 total incorrect transitions). Mean person→greeting ≈ 1.45s; median disengagement→arm motion ≈ 45ms; LLM latency ≈ 19.7s; end-to-end conversation ≈ 24.1s.
Stack: Raspberry Pi 4B, PCA9685, Adafruit ServoKit, Picamera2, MediaPipe, YOLOv8n, Python, JSONL, Vosk, Ollama

LLM Code Understanding Research

Undergraduate Research Assistant · 2025 – 2026

Developed reproducible GPU pipelines to test whether source-code embedding spaces capture program semantics for educational downstream tasks.

  • Built code summarization, clone-similarity, and correctness-oriented evaluation pipelines using CodeBERT, CodeT5, and DeepSeek-related code models.
  • Used BLEU, ROUGE, BERTScore, and cosine similarity; analyzed embedding behavior with PCA / t-SNE / UMAP across controlled code variants and clone types.
  • Implemented libclang-based AST/CFG/DFG generation and tokenizer/embedding diagnostics to probe structure vs semantic encoding.
  • Ran reproducible experiments on GPU infrastructure (including Compute Canada resources) and documented protocol, configs, and run logs.
  • [PUBLICATION] Resulted in Evaluating Source Code Embeddings from LLMs for Educational Downstream Tasks (IEEE UEMCON 2025, IBM Louis V. Gerstner Center).
